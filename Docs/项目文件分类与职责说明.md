# ZNQInterface 项目文件分类与职责说明

## 1. 整理原则

- `Services` 保存会执行通信、周期监控或设备操作的服务。
- `Models` 只保存枚举、定义和普通数据对象，不依赖具体界面。
- `ViewModels` 保存可绑定的界面状态、命令和页面协调逻辑。
- `Views` 保存 WPF 页面及其仅与界面生命周期相关的代码隐藏文件。
- `Controls` 保存可复用的 WPF 控件。
- `Resources` 保存全局样式、模板和资源字典。
- `Infrastructure` 保存 Prism 区域名、导航键等应用基础常量。
- `Data` 保存随程序发布、运行时读取的数据文件。
- `Docs` 保存项目接入、架构和文件职责文档。

## 2. 主要架构

```text
App
 ├─ Services/Communication/Ads  ADS连接和通用读写
 ├─ Services/Watchdog          HMI心跳与PLC看门狗反馈
 ├─ Services/Axes              14轴命令与ADS批量周期监控
 ├─ ViewModels                 页面状态和操作意图
 └─ Views/Resources/Controls   WPF显示层
```

看门狗只保留一个 `HmiWatchdogService`。它同时负责发送心跳、读取PLC反馈、生成综合状态，以及在主动断开ADS前暂停心跳。原来的 `HmiHeartbeatService`、`IHmiHeartbeatService` 和 `AdsHmiSymbols` 已合并移除。

## 4. Services：服务层

### 4.1 Communication/Ads：通用ADS通信

| 文件 | 作用 |
|---|---|
| `Services/Communication/Ads/IAdsConnectionService.cs` | 定义全应用统一的ADS连接、断开、状态通知和类型化读写接口。 |
| `Services/Communication/Ads/AdsConnectionService.cs` | 管理唯一`AdsClient`、本机PLC连接、自动重连、句柄缓存、单变量读写和Sum批量读取。 |
| `Services/Communication/Ads/AdsReadRequest.cs` | 描述一个批量读取的PLC叶子变量及其.NET类型。 |
| `Services/Communication/Ads/AdsConnectionOptions.cs` | 保存AMS端口、轮询周期、重连周期、命令脉冲时间和心跳周期等配置。 |
| `Services/Communication/Ads/AdsConnectionState.cs` | 定义未连接、连接中、已连接、重连中和故障等ADS状态。 |
| `Services/Communication/Ads/AdsConnectionStateChangedEventArgs.cs` | 携带ADS连接状态及界面显示文本。 |

### 4.2 Watchdog：HMI看门狗

| 文件 | 作用 |
|---|---|

| `Services/Watchdog/HmiWatchdogService.cs` | 使用UI线程定时器发送心跳，读取PLC在线、超时、控制许可和命令复位状态。 |
| `Services/Watchdog/HmiWatchdogSymbols.cs` | 集中保存PLC看门狗相关ADS符号名。 |
| `Services/Watchdog/HmiWatchdogStateChangedEventArgs.cs` | 向ViewModel发布综合看门狗状态和控制许可。 |

### 4.3 Axes：轴控制与监控

| 文件 | 作用 |
|---|---|
| `Services/Axes/IAxisCommandService.cs` | 定义使能、复位、停止、绝对/相对运动、点动和参数写入接口。 |
| `Services/Axes/AxisCommandService.cs` | 将WPF操作转换为PLC命令和参数写入，管理脉冲时序及主动断开前的停止掉使能。 |

## 10. 主要调用链

### ADS启动与状态监控

```text
App.OnInitialized
  -> IAdsConnectionService.StartAsync
  -> IHmiWatchdogService.StartAsync
  -> AxisMonitoringService.StartAsync
  -> AxisRuntimeData
  -> Overview / ManualControl
```

### 手动轴命令

```text
ManualControlView
  -> ManualControlViewModel
  -> IAxisCommandService
  -> AxisCommandService
  -> IAdsConnectionService
  -> PLC GVL_AxisRuntime.Axes[i]
```

### 主动断开ADS

```text
MainWindowViewModel
  -> HmiWatchdogService.Pause
  -> AxisCommandService.StopAndDisableAsync
  -> AdsConnectionService.DisconnectAsync
```

如果停止或断开失败且ADS仍连接，则调用 `HmiWatchdogService.Resume`，避免误触发PLC看门狗超时。

## 12. 后续扩展建议

当前两个流程文本只是界面预览。以后接入PLC整机流程状态时，可删除文本文件读取，将流程状态封装为独立的运行状态Model和监控Service，再由 `OverviewViewModel` 订阅更新。
